# Employee Leave & Attendance frontend

## Requirements

- Node.js `20.19+` or `22.13+`
- The FastAPI backend running at `http://127.0.0.1:8000`

## Run locally

From this directory:

```powershell
npm install
npm run dev
```

The local API URL is set in `.env.local` as `VITE_API_URL`. For another backend address, update that setting and restart Vite.

## Verify

```powershell
npm run lint
npm run build
```

See the root [README](../README.md) for backend startup, database seeding, and local demo account details.
