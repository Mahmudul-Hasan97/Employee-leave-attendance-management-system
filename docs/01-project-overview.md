# Project Overview

## Project Title

Employee Leave & Attendance Management System

---

## Introduction

The Employee Leave & Attendance Management System is a modern web-based application designed to automate employee attendance tracking and leave management. Built using **React.js** for a dynamic user interface and **FastAPI (Python)** for a high-performance backend, it replaces traditional paper-based processes with a secure digital platform. The system allows employees to check in, request leave, and monitor attendance records, while administrators and HR personnel can efficiently manage employee information, attendance, and leave approvals with **SQLite** data persistence.

---

## Objectives

The primary objectives of this project are:

- Automate employee attendance recording with RESTful APIs.
- Simplify leave application and approval workflows.
- Reduce manual paperwork through digital data storage.
- Improve data accuracy and transparency between HR and employees.
- Generate attendance and leave reports efficiently via the interactive React dashboard.
- Provide secure access for administrators and employees using role-based authentication.

---

## Technical Stack Overview

- **Frontend Framework:** React.js, JavaScript (ES6+), Bootstrap, HTML5/CSS3
- **Backend Framework:** Python (FastAPI), Uvicorn Server
- **Database:** SQLite
- **API Architecture:** RESTful APIs (communicating via JSON)
- **Version Control:** Git & GitHub

---

## Project Scope

The system includes the following core modules:

- **User Authentication:** Secure login for employees and admins.
- **Employee Management:** Add, update, and manage employee profiles.
- **Attendance Management:** Record daily clock-in/clock-out entries.
- **Leave Management:** Submit leave requests and check balance.
- **Leave Approval:** Admin workflow to approve or reject requests.
- **Attendance & Leave Reports:** Comprehensive reporting and analytics.
- **Interactive Dashboard:** Real-time summary view of system data.
- **User Profile Management:** View and update personal information.

Future enhancements may include biometric integration, mobile application support, and automated payroll system.
